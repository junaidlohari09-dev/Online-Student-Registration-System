# ONLINE STUDENT REGISTRATION SYSTEM

## Assignment 2 – VTU BCSL504

### 1. Project Description

The Online Student Registration System is a web-based application developed to simplify the student registration process. It allows students to enter their personal and academic information through an online registration form.

The system validates the submitted information and displays a registration confirmation page.

### 2. Objectives

- To develop an online student registration application.
- To collect student personal and academic details.
- To validate user input using JavaScript and jQuery.
- To process submitted information using PHP.
- To display a printable registration confirmation.

### 3. Technologies Used

- HTML5 – Website structure.
- CSS3 – Website styling and responsive design.
- JavaScript – Client-side validation.
- jQuery – Form validation.
- PHP – Server-side processing.
- XAMPP – Local web server.
- Visual Studio Code – Code editor.

### 4. Project Features

1. Student registration form.
2. Student name and USN collection.
3. Email and mobile number validation.
4. Course and semester selection.
5. Gender selection.
6. Address collection.
7. PHP form processing.
8. Registration ID generation.
9. Registration success page.
10. Print registration details.

### 5. Project Structure

Assignment-2/

- index.php

- script.js
- README.md

### 6. Installation and Execution

1. Install XAMPP on your computer.
2. Start the Apache server from XAMPP Control Panel.
3. Copy the Assignment-2 folder into:

   C:\xampp\htdocs\

4. Open the project folder in Visual Studio Code.
5. Open Google Chrome.
6. Enter the following URL:

   http://localhost/Assignment-2/

7. Fill in the student registration form.
8. Click Submit Registration.
9. View and print the registration confirmation.

### 7. Working Procedure

1. The student opens the registration website.
2. The student enters personal and academic details.
3. JavaScript and jQuery validate the entered information.
4. The form submits the data to process.php.
5. PHP performs server-side validation.
6. A registration ID is generated.
7. The system displays the registration success page.
8. The student can print the registration details.

### 8. Conclusion

The Online Student Registration System provides a simple and user-friendly interface for collecting student registration information. It demonstrates the practical implementation of HTML, CSS, JavaScript, jQuery and PHP in web application development.

**Note:** This project currently processes registration details without database storage. Submitted records are displayed on the confirmation page but are not permanently saved.
